# منصة ليكسورا (Lexora)

منصة قانونية ذكية موجهة للمستخدم في مصر، مصممة بواجهة متوافقة مع الهواتف المحمولة لتقديم تجربة استخدام سريعة ومنظمة.

## الرابط المباشر للتطبيق
يمكن الوصول إلى النسخة المنشورة من التطبيق عبر GitHub Pages من خلال الرابط التالي:
https://mohammedsaidsalim34-alt.github.io/lexora-egypt/

## أبرز أقسام ومزايا المنصة
- واجهة عربية (`RTL`) متجاوبة مع شاشات الموبايل.
- أدوات ومحتوى قانوني منظم لخدمة المستخدمين.
- إمكانية فتح التطبيق مباشرة من المتصفح أو تحويله لاحقاً إلى تطبيق أندرويد (`APK`).
